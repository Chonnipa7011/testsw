# Feature: แก้ไขโปรไฟล์หาเมท (Edit Roommate Profile)
Spec ID: SPEC-ERP-002 | Source: SRS ข้อ ... (FR-ERP) | Use case: UC-02
Owner: ทีม vista and friend | Status: Draft v3 | Updated: 2569-09-20

## Goal
นักศึกษาสามารถปรับปรุงข้อมูลและความต้องการในการหาเมท
เพื่อให้โปรไฟล์หาเมทเป็นข้อมูลล่าสุดของนักศึกษา

## Scope
### In scope
- เปิดดูข้อมูลโปรไฟล์หาเมทปัจจุบัน
- แก้ไขข้อมูลโปรไฟล์หาเมท
- แก้ไขความต้องการเกี่ยวกับเมท
- ตรวจสอบข้อมูลก่อนบันทึก
- บันทึกข้อมูลโปรไฟล์ที่แก้ไข
- แสดงข้อความเมื่อแก้ไขโปรไฟล์สำเร็จ
- แก้ไขสถานะเปิดให้ค้นหาโปรไฟล์

### Out of scope
- การสร้างโปรไฟล์หาเมทใหม่
- การลบโปรไฟล์หาเมท
- การค้นหาหรือจับคู่รูมเมท ยกเว้นการอัปเดตข้อมูลโปรไฟล์ให้พร้อมแสดงในผลการค้นหา
- การติดต่อหรือแชทกับรูมเมท

## Constraints
- CON-ERP-01 นักศึกษาต้องเข้าสู่ระบบก่อนจึงสามารถแก้ไขโปรไฟล์หาเมทได้
- CON-ERP-02 นักศึกษาต้องมีโปรไฟล์หาเมทก่อนจึงสามารถแก้ไขข้อมูลได้
- CON-ERP-03 ข้อมูลที่แก้ไขต้องครบถ้วนก่อนจึงสามารถบันทึกได้
- CON-ERP-04 ข้อมูลที่แก้ไขต้องผ่านการตรวจสอบความถูกต้องก่อนบันทึก
- CON-ERP-05 หากข้อมูลไม่ครบหรือไม่ถูกต้อง ระบบต้องไม่บันทึกข้อมูลใหม่
- CON-ERP-06 ชื่อและเพศเป็นข้อมูลที่ไม่อนุญาตให้แก้ไข
- CON-ERP-07 การแก้ไขสถานะเปิดให้ค้นหาต้องเป็นการเปลี่ยนสถานะของเจ้าของโปรไฟล์เท่านั้น

## Requirements
- FR-ERP-01 ระบบต้องให้นักศึกษาสามารถเลือกเมนู "โปรไฟล์" ได้
- FR-ERP-02 ระบบต้องแสดงข้อมูลโปรไฟล์หาเมทปัจจุบันของนักศึกษา
- FR-ERP-03 ระบบต้องให้นักศึกษาสามารถแก้ไขข้อมูลโปรไฟล์หาเมทได้
- FR-ERP-04 ระบบต้องให้นักศึกษาสามารถแก้ไขพฤติกรรมการนอนและข้อมูลโซเชียลช่องทางอื่นได้
- FR-ERP-05 ระบบต้องตรวจสอบข้อมูลที่นักศึกษาแก้ไขก่อนบันทึก
- FR-ERP-06 หากข้อมูลไม่ครบหรือไม่ถูกต้อง ระบบต้องแจ้งเตือนและให้นักศึกษาแก้ไขข้อมูล
- FR-ERP-07 เมื่อข้อมูลผ่านการตรวจสอบ ระบบต้องบันทึกข้อมูลโปรไฟล์ใหม่
- FR-ERP-08 เมื่อบันทึกข้อมูลสำเร็จ ระบบต้องแสดงข้อความว่าแก้ไขโปรไฟล์สำเร็จ
- FR-ERP-09 ระบบต้องให้นักศึกษาสามารถเปิดหรือปิดสถานะให้โปรไฟล์ปรากฏในผลการค้นหาได้

### Editable fields and validation rules
- ฟิลด์ที่แก้ไขได้ ได้แก่ อายุ คณะ ชั้นปี รูปโปรไฟล์ เบอร์โทรศัพท์ ประเภทห้องพัก พฤติกรรมการนอน โซเชียลช่องทางอื่น ได้แก่ Facebook, Instagram, LINE และ TikTok โดยรับ username หรือ URL และสถานะเปิดให้ค้นหา
- ชื่อและเพศเป็นฟิลด์ที่แก้ไขไม่ได้
- ใช้ validation เดียวกับการสร้างโปรไฟล์ v3: อายุเป็นจำนวนเต็ม 18–25 ปี คณะและชั้นปีเลือกจากรายการที่กำหนด รูปโปรไฟล์เป็น JPG หรือ PNG ขนาดไม่เกิน 5 MB เบอร์โทรศัพท์มีตัวเลข 10 หลักหลังตัดช่องว่างหรือขีดคั่น และประเภทห้องพักเป็นห้องแอร์ 1–4 คนหรือห้องพัดลม 1–3 คน
- พฤติกรรมการนอนต้องเลือกอย่างน้อยหนึ่งรายการจาก กรน, กัดฟัน, นอนดิ้น หรือ ไม่มีพฤติกรรมดังกล่าว หากเลือก อื่น ๆ ต้องกรอกข้อความเพิ่มเติม
- เมื่อเปิดสถานะให้ค้นหา โปรไฟล์ต้องปรากฏในผลการค้นหาได้ทันทีหลังบันทึกสำเร็จ และเมื่อปิดสถานะต้องไม่ปรากฏในผลการค้นหา
- การเปลี่ยนสถานะจากฟีเจอร์นี้ไม่แทนที่ flow ของ UC-10; หากการปิดสถานะต้องจัดการคำขอที่รอการตอบรับ ให้ใช้กฎของ UC-10 ร่วมด้วย
- หากการบันทึกล้มเหลว ระบบต้องคงข้อมูลเดิมทั้งหมด ไม่บันทึกข้อมูลบางส่วน และแจ้งให้นักศึกษาลองใหม่

## Quality Requirements
- NFR-ERP-01 ระบบต้องอนุญาตให้เฉพาะนักศึกษาที่เข้าสู่ระบบและเป็นเจ้าของโปรไฟล์สามารถแก้ไขโปรไฟล์ได้
- NFR-ERP-02 ระบบต้องไม่เปลี่ยนแปลงข้อมูลโปรไฟล์ หากข้อมูลที่แก้ไขไม่ผ่านการตรวจสอบ
- NFR-ERP-03 ในการทดสอบกับนักศึกษาที่ไม่เคยใช้ฟังก์ชันแก้ไข 5 คน อย่างน้อย 80% ต้องแก้ไขโปรไฟล์สำเร็จโดยไม่รับคำแนะนำ
- NFR-ERP-04 ระบบต้องอัปเดตการปรากฏในผลการค้นหาให้สอดคล้องกับสถานะเปิดให้ค้นหาล่าสุด

## Acceptance Criteria
- [ ] AC-ERP-01 (FR-ERP-01, FR-ERP-02)
     Given นักศึกษาเข้าสู่ระบบแล้วและมีโปรไฟล์หาเมท
     When นักศึกษาเลือกเมนู "โปรไฟล์"
     Then ระบบแสดงข้อมูลโปรไฟล์หาเมทปัจจุบัน

- [ ] AC-ERP-02 (FR-ERP-03, FR-ERP-04)
     Given นักศึกษาเปิดดูโปรไฟล์หาเมทของตนเอง
When นักศึกษาแก้ไขข้อมูลที่อนุญาตและพฤติกรรมการนอน
     Then ระบบรับข้อมูลที่นักศึกษาแก้ไข

- [ ] AC-ERP-02A (CON-ERP-06)
Given นักศึกษาเปิดดูโปรไฟล์หาเมทของตนเอง
When นักศึกษาพยายามแก้ไขชื่อหรือเพศ
Then ระบบไม่อนุญาตให้แก้ไขฟิลด์ดังกล่าว

- [ ] AC-ERP-02B (CON-ERP-07, FR-ERP-09)
Given นักศึกษาเปิดดูโปรไฟล์หาเมทของตนเอง
When นักศึกษาเปลี่ยนสถานะเปิดให้ค้นหา
Then ระบบรับการเปลี่ยนสถานะของเจ้าของโปรไฟล์และไม่อนุญาตให้เปลี่ยนสถานะของโปรไฟล์ผู้อื่น

- [ ] AC-ERP-03 (FR-ERP-05, FR-ERP-06)
     Given นักศึกษาแก้ไขข้อมูลโปรไฟล์
     When นักศึกษากดยืนยันการแก้ไขโดยข้อมูลไม่ครบหรือไม่ถูกต้อง
     Then ระบบแจ้งเตือนและให้นักศึกษาแก้ไขข้อมูลและไม่บันทึกข้อมูลใหม่

- [ ] AC-ERP-04 (FR-ERP-05, FR-ERP-07, FR-ERP-08)
     Given นักศึกษาแก้ไขข้อมูลโปรไฟล์ครบและข้อมูลถูกต้อง
     When นักศึกษากดยืนยันการแก้ไข
     Then ระบบตรวจสอบและบันทึกข้อมูลใหม่และแสดงข้อความว่าแก้ไขโปรไฟล์สำเร็จ

- [ ] AC-ERP-04A (FR-ERP-07, NFR-ERP-02)
Given นักศึกษาแก้ไขข้อมูลโปรไฟล์ครบและข้อมูลถูกต้อง
When การบันทึกข้อมูลล้มเหลว
Then ระบบคงข้อมูลเดิมทั้งหมด ไม่บันทึกข้อมูลบางส่วน แจ้งข้อผิดพลาด และให้นักศึกษาลองใหม่ได้

- [ ] AC-ERP-05 (NFR-ERP-01)
     Given นักศึกษาเข้าสู่ระบบแล้ว
     When นักศึกษาพยายามแก้ไขโปรไฟล์ของนักศึกษาคนอื่น
     Then ระบบปฏิเสธการแก้ไขโปรไฟล์ดังกล่าว

- [ ] AC-ERP-06 (CON-ERP-02)
Given นักศึกษาเข้าสู่ระบบแล้วแต่ยังไม่มีโปรไฟล์หาเมท
When นักศึกษาเลือกเมนู "โปรไฟล์"
Then ระบบแจ้งว่ายังไม่มีโปรไฟล์และพาไปยังหน้าสร้างโปรไฟล์หาเมท

- [ ] AC-ERP-07 (ASM-ERP-04)
Given นักศึกษาแก้ไขข้อมูลโปรไฟล์ของตนเองครบและถูกต้อง
When ระบบบันทึกข้อมูลสำเร็จและสถานะเปิดให้ค้นหาเป็น "เปิด"
Then ข้อมูลใหม่ปรากฏในผลการค้นหาของนักศึกษาคนอื่นทันที

- [ ] AC-ERP-07A (NFR-ERP-04)
Given นักศึกษาแก้ไขโปรไฟล์สำเร็จและสถานะเปิดให้ค้นหาเป็น "ปิด"
When นักศึกษาคนอื่นค้นหาเมท
Then โปรไฟล์ดังกล่าวไม่ปรากฏในผลการค้นหา

- [ ] AC-ERP-08 (NFR-ERP-03)
Given นักศึกษาที่ไม่เคยใช้ฟังก์ชันแก้ไขจำนวน 5 คน
When นักศึกษาแต่ละคนแก้ไขโปรไฟล์หาเมท
Then อย่างน้อย 4 คนแก้ไขโปรไฟล์สำเร็จโดยไม่รับคำแนะนำ

## Assumptions & Open Questions
- ASM-ERP-01 นักศึกษาต้องเข้าสู่ระบบก่อนใช้งานฟังก์ชันแก้ไขโปรไฟล์หาเมท
- ASM-ERP-02 นักศึกษาหนึ่งคนมีโปรไฟล์หาเมทได้หนึ่งโปรไฟล์
- ASM-ERP-03 ระบบมีข้อมูลโปรไฟล์เดิมของนักศึกษาอยู่แล้วก่อนเข้าสู่ฟังก์ชันนี้
- ASM-ERP-04 ข้อมูลที่แก้ไขสำเร็จจะถูกนำไปใช้เป็นข้อมูลล่าสุดของโปรไฟล์
- ASM-ERP-05 สถานะเปิดให้ค้นหาเป็นข้อมูลของเจ้าของโปรไฟล์ และผลการค้นหาต้องใช้สถานะล่าสุดหลังบันทึกสำเร็จ

- Q-ERP-01 นักศึกษาสามารถแก้ไขข้อมูลทุกช่องในโปรไฟล์ได้หรือไม่?
-> ตอบแล้ว: แก้ไขได้ทุกฟิลด์ยกเว้นชื่อและเพศ
- Q-ERP-02 มีข้อมูลใดบ้างที่ไม่อนุญาตให้แก้ไข?
-> ตอบแล้ว: ชื่อและเพศ
- Q-ERP-03 เมื่อแก้ไขโปรไฟล์สำเร็จ ข้อมูลใหม่จะแสดงในผลการค้นหาทันทีหรือไม่?
-> ตอบแล้ว: แสดงทันทีเมื่อสถานะเปิดให้ค้นหาเป็น "เปิด"; หากสถานะเป็น "ปิด" จะไม่แสดง
- Q-ERP-04 การเปลี่ยนสถานะจากฟีเจอร์แก้ไขโปรไฟล์เกี่ยวข้องกับการปฏิเสธคำขอที่รออยู่หรือไม่?
-> ตอบแล้ว: การจัดการคำขอที่รออยู่ใช้ flow ของ UC-10 ไม่ใช่การแก้ไขข้อมูลโปรไฟล์ทั่วไป
