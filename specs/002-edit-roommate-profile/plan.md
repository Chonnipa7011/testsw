# Plan v1: Align edit roommate profile specification

## Problem and approach

ปรับ [spec.md](spec.md) ให้สอดคล้องกับ [spec.md](../001-roommate-profile/spec.md) ฉบับ Draft v3 โดยทำให้รายการฟิลด์ validation สิทธิ์การแก้ไข สถานะเปิดให้ค้นหา และผลกระทบต่อผลค้นหาชัดเจนและไม่ขัดกับฟีเจอร์ปิดสถานะหาเมท

## Tasks

1. ตรวจสอบความสอดคล้องของฟิลด์และ validation ระหว่างการสร้างกับการแก้ไขโปรไฟล์
2. เพิ่มขอบเขตการแก้ไขสถานะเปิดให้ค้นหา พร้อมแยกสิทธิ์จากฟีเจอร์ปิดสถานะหาเมท
3. ปรับ requirements, acceptance criteria, assumptions และ open questions ให้ครอบคลุมการเผยแพร่และการบันทึกล้มเหลว
4. ปรับ traceability ให้ครอบคลุมข้อกำหนดและ acceptance criteria ใหม่
5. ตรวจ diff/markdown consistency และ commit เป็น `Draft v3`

## Notes and considerations

- ชื่อและเพศยังคงแก้ไขไม่ได้ตามข้อสรุปเดิม
- ฟิลด์ที่แก้ไขได้ต้องใช้ validation เดียวกับโปรไฟล์ v3
- การแก้ไขสถานะเปิดให้ค้นหาต้องทำให้ผลค้นหาสอดคล้องทันทีหลังบันทึกสำเร็จ
- ต้องไม่ทำให้ขอบเขตการปิดสถานะใน UC-10 ขัดแย้งกัน จึงควรระบุว่า UC-10 เป็น flow เฉพาะสำหรับการปิด/เปิดสถานะพร้อมการจัดการคำขอที่รอ
- ต้องคงการเปลี่ยนแปลงที่มีอยู่เดิมใน working tree และไม่แตะไฟล์ที่ไม่เกี่ยวข้อง
