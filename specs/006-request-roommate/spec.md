# Feature: ส่งคำขอเป็นเมท (Roommate Request)
Spec ID: SPEC-RRS-006 | Source: SRS ข้อ ... (FR-RRS) | Use case: UC-06
Owner: ทีม vista and friend | Status: Draft v3 | Updated: 2569-09-20

## Goal
นักศึกษาสามารถส่งคำขอเป็นเมทไปยังผู้ที่สนใจ
เพื่อขอจับคู่เป็นรูมเมทและรอการตอบรับจากผู้รับคำขอ

## Scope
### In scope
- เลือกโปรไฟล์ของผู้ที่สนใจ
- เลือกส่งคำขอเป็นเมท
- ตรวจสอบสถานะของผู้รับ
- ตรวจสอบคำขอที่มีอยู่แล้ว
- บันทึกคำขอเป็นเมท
- ส่งการแจ้งเตือนไปยังผู้รับ
- แสดงสถานะรอการตอบรับ

### Out of scope
- การสร้างโปรไฟล์หาเมท (UC-01)
- การแก้ไขโปรไฟล์หาเมท (UC-02)
- การระบุความต้องการหาเมท (UC-03)
- การค้นหาเมท (UC-04)
- การตอบรับหรือปฏิเสธคำขอเป็นเมท (UC-07)
- การยกเลิกคำขอเป็นเมท (ฟีเจอร์แยกในภายหลัง) (UC-07)
- การติดต่อหรือแชทกับรูมเมท (UC-05)

## Constraints
- CON-RRS-01 นักศึกษาต้องเข้าสู่ระบบก่อนจึงสามารถส่งคำขอเป็นเมทได้
- CON-RRS-02 นักศึกษาต้องมีโปรไฟล์หาเมทก่อนจึงสามารถส่งคำขอเป็นเมทได้
- CON-RRS-03 ผู้รับคำขอต้องอยู่ในสถานะหาเมทจึงสามารถส่งคำขอได้
- CON-RRS-04 ระบบต้องตรวจสอบข้อมูลและสถานะของผู้รับก่อนบันทึกคำขอ
- CON-RRS-05 นักศึกษาต้องไม่สามารถส่งคำขอเป็นเมทซ้ำไปยังผู้รับคนเดิมได้ขณะที่คำขอเดิมยังรอการตอบรับ
- CON-RRS-06 หากผู้รับไม่ได้อยู่ในสถานะหาเมท หรือมีคำขอที่ยังรอการตอบรับจากผู้ส่งอยู่แล้ว ระบบต้องไม่บันทึกคำขอใหม่
- CON-RRS-07 ผู้รับสามารถมีคำขอที่รอการตอบรับจากหลายคนพร้อมกันได้
- CON-RRS-08 ผู้ส่งและผู้รับต้องไม่เป็นนักศึกษาคนเดียวกัน
- CON-RRS-09 คำขอที่อยู่ในสถานะรอการตอบรับไม่มีวันหมดอายุอัตโนมัติ
- CON-RRS-10 คำขอหนึ่งรายการอาจมีข้อความประกอบแบบไม่บังคับ ความยาวไม่เกิน 500 ตัวอักษร
- CON-RRS-11 ระบบต้องตรวจสอบสถานะผู้รับและคำขอเดิมแบบ atomic อีกครั้งก่อนบันทึกคำขอ
- CON-RRS-12 หากมีคำขอที่จับคู่สำเร็จระหว่างผู้ส่งกับผู้รับอยู่แล้ว ผู้ส่งต้องไม่สามารถส่งคำขอใหม่ได้จนกว่าการจับคู่เดิมจะถูกยกเลิก

## Requirements
- FR-RRS-01 ระบบต้องให้นักศึกษาสามารถเลือกโปรไฟล์ของผู้ที่สนใจได้
- FR-RRS-02 ระบบต้องให้นักศึกษาสามารถเลือก "ส่งคำขอเป็นเมท" ได้
- FR-RRS-03 ระบบต้องตรวจสอบสถานะของผู้รับก่อนส่งคำขอ
- FR-RRS-04 ระบบต้องตรวจสอบว่ามีคำขอเป็นเมทกับผู้รับอยู่แล้วหรือไม่
- FR-RRS-05 หากผู้รับอยู่ในสถานะหาเมทและยังไม่มีคำขอ ระบบต้องบันทึกคำขอเป็นเมท
- FR-RRS-06 ระบบต้องส่งการแจ้งเตือนไปยังผู้รับเมื่อบันทึกคำขอสำเร็จ
- FR-RRS-07 ระบบต้องแสดงสถานะของคำขอเป็น "รอการตอบรับ"
- FR-RRS-08 หากผู้รับไม่ได้อยู่ในสถานะหาเมท ระบบต้องไม่อนุญาตให้ส่งคำขอ
- FR-RRS-09 หากมีคำขอที่ยังรอการตอบรับ หรือมีการจับคู่สำเร็จกับผู้รับอยู่แล้ว ระบบต้องแจ้งว่าไม่สามารถส่งคำขอซ้ำได้
- FR-RRS-10 ระบบต้องป้องกันไม่ให้นักศึกษาส่งคำขอให้โปรไฟล์ของตนเอง
- FR-RRS-11 ระบบต้องแสดงสถานะคำขอที่มีอยู่ ได้แก่ รอการตอบรับ, ตอบรับ, ปฏิเสธ และยกเลิก
- FR-RRS-12 เมื่อมีคำขอใหม่ ระบบต้องแจ้งชื่อผู้ส่ง รูปโปรไฟล์ และเวลาที่ส่ง และเปิดรายละเอียดคำขอเมื่อกดแจ้งเตือน
- FR-RRS-13 หากการแจ้งเตือนคำขอไม่สำเร็จ ระบบต้องคงคำขอที่บันทึกไว้และแสดงสถานะรอการตอบรับ
- FR-RRS-14 ระบบต้องให้ผู้ส่งกรอกข้อความประกอบคำขอแบบไม่บังคับ ความยาวไม่เกิน 500 ตัวอักษร
- FR-RRS-15 ระบบต้องตรวจสอบสถานะผู้รับและคำขอเดิมแบบ atomic ก่อนบันทึกคำขอ และแจ้งเหตุผลหากตรวจสอบไม่ผ่าน
- FR-RRS-16 ระบบต้องลองส่งการแจ้งเตือนคำขอซ้ำอัตโนมัติไม่เกิน 3 ครั้งเมื่อการแจ้งเตือนครั้งแรกล้มเหลว

## Quality Requirements
- NFR-RRS-01 ระบบต้องอนุญาตให้เฉพาะนักศึกษาที่เข้าสู่ระบบแล้วสามารถส่งคำขอเป็นเมทได้
- NFR-RRS-02 ระบบต้องไม่บันทึกคำขอ หากผู้รับไม่ได้อยู่ในสถานะหาเมท หรือมีคำขออยู่แล้ว
- NFR-RRS-04 หากมีการจับคู่สำเร็จกับผู้รับเดิม ระบบต้องไม่บันทึกคำขอใหม่จนกว่าการจับคู่เดิมจะถูกยกเลิก
- NFR-RRS-05 ระบบต้องป้องกันไม่ให้คำขอซ้ำถูกบันทึกจากการส่งคำขอพร้อมกัน
- NFR-RRS-03 ในการทดสอบกับนักศึกษาที่ไม่เคยส่งคำขอ 5 คน อย่างน้อย 80% ต้องส่งคำขอสำเร็จโดยไม่รับคำแนะนำ

## Acceptance Criteria
- [ ] AC-RRS-01 (FR-RRS-01, FR-RRS-02)
      Given นักศึกษาเข้าสู่ระบบแล้วและมีโปรไฟล์หาเมท
      When นักศึกษาเลือกโปรไฟล์ของผู้ที่สนใจและเลือก "ส่งคำขอเป็นเมท"
      Then ระบบดำเนินการตรวจสอบข้อมูลของผู้รับ

- [ ] AC-RRS-02 (FR-RRS-03)
      Given นักศึกษาเลือกส่งคำขอเป็นเมท
      When ระบบตรวจสอบสถานะของผู้รับ
      Then ระบบตรวจสอบว่าผู้รับอยู่ในสถานะหาเมทหรือไม่

- [ ] AC-RRS-03 (FR-RRS-04)
      Given ผู้รับอยู่ในสถานะหาเมท
      When ระบบตรวจสอบคำขอ
      Then ระบบตรวจสอบว่ามีคำขอเป็นเมทกับผู้รับอยู่แล้วหรือไม่

- [ ] AC-RRS-04 (FR-RRS-05, FR-RRS-06, FR-RRS-07)
      Given ผู้รับอยู่ในสถานะหาเมทและยังไม่มีคำขอเป็นเมท
      When นักศึกษาส่งคำขอเป็นเมทพร้อมหรือไม่พร้อมข้อความประกอบที่ไม่เกิน 500 ตัวอักษร
      Then ระบบบันทึกคำขอเป็น "รอการตอบรับ" และส่งการแจ้งเตือนไปยังผู้รับ

- [ ] AC-RRS-04A (FR-RRS-06, FR-RRS-13)
      Given ผู้รับอยู่ในสถานะหาเมทและยังไม่มีคำขอซ้ำจากผู้ส่ง
      When ระบบบันทึกคำขอสำเร็จแต่การแจ้งเตือนไม่สำเร็จ
      Then ระบบคงคำขอไว้ แสดงสถานะ "รอการตอบรับ" และแจ้งสถานะการแจ้งเตือนล้มเหลวโดยไม่ลบคำขอ

- [ ] AC-RRS-05 (FR-RRS-08)
      Given ผู้รับไม่ได้อยู่ในสถานะหาเมท
      When นักศึกษาพยายามส่งคำขอเป็นเมท
      Then ระบบไม่อนุญาตให้ส่งคำขอ

- [ ] AC-RRS-06 (FR-RRS-09)
      Given มีคำขอเป็นเมทกับผู้รับอยู่แล้ว
      When นักศึกษาพยายามส่งคำขอเป็นเมทซ้ำ
      Then ระบบแจ้งว่า "มีคำขอเป็นเมทกับผู้รับรายนี้อยู่แล้ว และยังอยู่ระหว่างรอการตอบรับ" และไม่บันทึกคำขอใหม่

- [ ] AC-RRS-06A (CON-RRS-11, FR-RRS-15)
      Given ผู้ส่งเปิดหน้าส่งคำขอไว้ และสถานะผู้รับหรือคำขอเดิมเปลี่ยนแปลงก่อนยืนยัน
      When นักศึกษายืนยันส่งคำขอ
      Then ระบบตรวจสอบสถานะและคำขอเดิมแบบ atomic อีกครั้ง และไม่บันทึกคำขอหากตรวจสอบไม่ผ่านพร้อมแจ้งเหตุผล

- [ ] AC-RRS-07 (NFR-RRS-01)
      Given นักศึกษายังไม่ได้เข้าสู่ระบบ
      When นักศึกษาพยายามส่งคำขอเป็นเมท
      Then ระบบปฏิเสธการเข้าใช้งานและให้นักศึกษาเข้าสู่ระบบก่อน

- [ ] AC-RRS-08 (CON-RRS-07)
      Given ผู้รับมีคำขอที่ยังรอการตอบรับจากนักศึกษาหลายคน
      When นักศึกษาคนใหม่ส่งคำขอไปยังผู้รับ
      Then ระบบอนุญาตให้บันทึกคำขอใหม่หากผู้รับยังอยู่ในสถานะหาเมท

- [ ] AC-RRS-09 (CON-RRS-08, FR-RRS-10)
      Given นักศึกษาเลือกโปรไฟล์ของตนเอง
      When นักศึกษาเลือก "ส่งคำขอเป็นเมท"
      Then ระบบไม่บันทึกคำขอและแจ้งว่าไม่สามารถส่งคำขอเป็นเมทให้ตนเองได้

- [ ] AC-RRS-10 (FR-RRS-11)
      Given นักศึกษามีคำขอเป็นเมทที่เกี่ยวข้อง
      When นักศึกษาเปิดหน้ารายการคำขอ
      Then ระบบแสดงสถานะ รอการตอบรับ, ตอบรับ, ปฏิเสธ หรือ ยกเลิก ตามสถานะของแต่ละคำขอ

- [ ] AC-RRS-11 (FR-RRS-12)
      Given ผู้รับได้รับคำขอใหม่
      When ระบบส่งการแจ้งเตือน
      Then การแจ้งเตือนแสดงชื่อผู้ส่ง รูปโปรไฟล์ และเวลาที่ส่ง และเมื่อกดจะแสดงรายละเอียดคำขอ

- [ ] AC-RRS-12 (CON-RRS-02)
      Given นักศึกษาเข้าสู่ระบบแล้วแต่ยังไม่มีโปรไฟล์หาเมท
      When นักศึกษาพยายามส่งคำขอเป็นเมท
      Then ระบบแจ้งว่ายังไม่มีโปรไฟล์และพาไปยังหน้าสร้างโปรไฟล์หาเมท

- [ ] AC-RRS-13 (FR-RRS-09)
      Given คำขอเดิมกับผู้รับสิ้นสุดแล้วด้วยสถานะ ปฏิเสธ หรือ ยกเลิก
      When นักศึกษาส่งคำขอไปยังผู้รับคนเดิมอีกครั้ง
      Then ระบบอนุญาตให้บันทึกคำขอใหม่

- [ ] AC-RRS-13A (CON-RRS-12, NFR-RRS-04)
      Given ผู้ส่งและผู้รับมีการจับคู่สำเร็จอยู่แล้ว
      When ผู้ส่งพยายามส่งคำขอเป็นเมทใหม่ไปยังผู้รับคนเดิม
      Then ระบบไม่บันทึกคำขอใหม่และแจ้งว่าต้องยกเลิกการจับคู่เดิมก่อน

- [ ] AC-RRS-04B (FR-RRS-14)
      Given นักศึกษาอยู่ในหน้าส่งคำขอเป็นเมท
      When นักศึกษากรอกข้อความประกอบยาวเกิน 500 ตัวอักษร
      Then ระบบแจ้งข้อผิดพลาดและไม่อนุญาตให้ส่งคำขอ

- [ ] AC-RRS-11A (FR-RRS-16)
      Given ระบบบันทึกคำขอสำเร็จแต่การแจ้งเตือนผู้รับล้มเหลว
      When ระบบลองส่งการแจ้งเตือนซ้ำ
      Then ระบบลองซ้ำไม่เกิน 3 ครั้ง และหากยังไม่สำเร็จจะคงคำขอเป็น "รอการตอบรับ" พร้อมแสดงสถานะแจ้งเตือนล้มเหลว

- [ ] AC-RRS-15 (CON-RRS-09)
      Given คำขอเป็นเมทอยู่ในสถานะ "รอการตอบรับ"
      When เวลาผ่านไปโดยผู้รับยังไม่ตอบคำขอ
      Then ระบบยังคงสถานะ "รอการตอบรับ" และไม่หมดอายุคำขออัตโนมัติ

- [ ] AC-RRS-14 (NFR-RRS-03)
      Given นักศึกษาที่ไม่เคยใช้ฟังก์ชันส่งคำขอจำนวน 5 คน
      When นักศึกษาแต่ละคนส่งคำขอเป็นเมท
      Then อย่างน้อย 4 คนส่งคำขอสำเร็จโดยไม่รับคำแนะนำ

## Assumptions & Open Questions
- ASM-RRS-01 นักศึกษาต้องเข้าสู่ระบบก่อนใช้งานฟังก์ชันส่งคำขอเป็นเมท
- ASM-RRS-02 นักศึกษาต้องมีโปรไฟล์หาเมทก่อนส่งคำขอ
- ASM-RRS-03 ผู้รับคำขอต้องมีโปรไฟล์หาเมทและอยู่ในสถานะหาเมท
- ASM-RRS-04 ระบบสามารถตรวจสอบคำขอเป็นเมทที่มีอยู่แล้วได้
- ASM-RRS-05 ระบบมีระบบแจ้งเตือนสำหรับผู้รับคำขอ

- Q-RRS-01 ผู้รับสามารถได้รับคำขอจากนักศึกษาหลายคนพร้อมกันได้หรือไม่?
-> ตอบแล้ว: ได้ ผู้รับรับคำขอที่รอการตอบรับจากหลายคนพร้อมกันได้
- Q-RRS-02 เมื่อผู้รับได้รับคำขอแล้ว สถานะหาเมทจะเปลี่ยนเป็นอะไร?
-> ตอบแล้ว: คงสถานะกำลังหาเมทไว้จนกว่าจะตอบรับคำขอ
- Q-RRS-03 ผู้ส่งสามารถยกเลิกคำขอที่ส่งไปแล้วได้หรือไม่?
-> ตอบแล้ว: ยังไม่รวมในฟีเจอร์นี้ และจะเป็นฟีเจอร์แยกในภายหลัง
- Q-RRS-04 เมื่อมีคำขอซ้ำ ระบบควรแสดงข้อความแจ้งเตือนว่าอย่างไร?
-> ตอบแล้ว: มีคำขอเป็นเมทกับผู้รับรายนี้อยู่แล้ว และยังอยู่ระหว่างรอการตอบรับ
- Q-RRS-05 คำขอเป็นเมทมีข้อความประกอบหรือไม่?
-> ตอบแล้ว: มีข้อความประกอบแบบไม่บังคับ ความยาวไม่เกิน 500 ตัวอักษร
- Q-RRS-06 หากสถานะผู้รับหรือคำขอเดิมเปลี่ยนระหว่างเปิดหน้าส่งคำขอ ระบบต้องทำอย่างไร?
-> ตอบแล้ว: ตรวจสอบสถานะและคำขอเดิมแบบ atomic อีกครั้งก่อนบันทึก และไม่บันทึกหากตรวจสอบไม่ผ่าน
- Q-RRS-07 หากมีการจับคู่สำเร็จกับผู้รับเดิมแล้ว จะส่งคำขอใหม่ได้หรือไม่?
-> ตอบแล้ว: ส่งไม่ได้จนกว่าการจับคู่เดิมจะถูกยกเลิก
- Q-RRS-08 หากแจ้งเตือนผู้รับล้มเหลว ระบบต้องลองซ้ำกี่ครั้ง?
-> ตอบแล้ว: ลองส่งซ้ำอัตโนมัติ 3 ครั้ง แล้วคงคำขอเป็น "รอการตอบรับ"
