# Plan v1: Align roommate preference specification

## Problem and approach

ปรับ [spec.md](spec.md) จาก Draft v2 เป็น Draft v3 ให้สอดคล้องกับโปรไฟล์หาเมทและการค้นหาเมท พร้อมทบทวนรายละเอียดตัวเลือก, validation, acceptance criteria และ traceability ให้ชัดเจนและทดสอบได้

## Scope decisions

- ทบทวนรายละเอียดตัวเลือกและ validation ของความต้องการหาเมททั้งหมด ไม่จำกัดเฉพาะจุดที่ขัดแย้งกับสเปกอื่น
- `จำนวนคนในห้อง` และ `รูปแบบห้อง` หมายถึงห้องที่ผู้ใช้ต้องการ และใช้ช่วงค่าเดียวกับโปรไฟล์: ห้องแอร์ 1–4 คน และห้องพัดลม 1–3 คน
- `ข้อมูลเพิ่มเติม` เป็นข้อมูลเสริมแบบข้อความอิสระ ไม่เกิน 500 ตัวอักษร และหากเริ่มกรอกต้องไม่เป็นข้อความว่าง

## Tasks

1. ตรวจสอบและปรับฟิลด์ความต้องการให้สอดคล้องกับโปรไฟล์และตัวกรองค้นหา
2. ปรับ validation และข้อกำหนดข้อมูลเพิ่มเติมให้ทดสอบได้
3. ปรับ requirements, acceptance criteria และ failure handling ให้ครอบคลุมการสร้าง/แก้ไข/นำไปใช้
4. ปรับ assumptions, open questions และ traceability ให้สอดคล้องกับข้อกำหนด v3
5. ตรวจ diff และ markdown consistency แล้ว commit เป็น `Draft v3`

## Notes and considerations

- ต้องคงขอบเขตว่า UC-03 จัดการการจัดเก็บความต้องการ ไม่รวม flow ค้นหา/จับคู่โดยตรง
- ต้องแยกพฤติกรรมการนอนของเจ้าของโปรไฟล์ออกจากความต้องการด้านพฤติกรรมของเมท
- ข้อมูลความต้องการที่บันทึกสำเร็จต้องพร้อมใช้ในการค้นหาและจับคู่ทันที
- ต้องไม่แก้ไฟล์ attachment แบบ read-only และต้องคงการเปลี่ยนแปลงที่ไม่เกี่ยวข้องใน working tree
