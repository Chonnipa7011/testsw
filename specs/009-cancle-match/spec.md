# Feature: ยกเลิกการจับคู่ (Cancel Match)
Spec ID: SPEC-CCM-009 | Source: SRS ข้อ ... (FR-CCM) | Use case: UC-09
Owner: ทีม vista and friend | Status: Draft v3 | Updated: 2569-09-20

## Goal
นักศึกษาสามารถยกเลิกการจับคู่กับรูมเมทที่จับคู่สำเร็จแล้ว
เพื่อให้สามารถกลับไปค้นหาและจับคู่กับเมทใหม่ได้

## Scope
### In scope
- เปิดหน้าสถานะการจับคู่
- เลือกคู่ที่ต้องการยกเลิก
- เลือกยกเลิกการจับคู่
- แสดงข้อความยืนยันการยกเลิก
- ยืนยันการยกเลิก
- เปลี่ยนสถานะการจับคู่
- แจ้งผลการยกเลิก

### Out of scope
- การส่งคำขอเป็นเมท (UC-06)
- การรับหรือปฏิเสธคำขอเป็นเมท (UC-07)
- การแสดงสถานะการจับคู่ (UC-08)
- การค้นหาเมท (UC-04)
- การสร้างโปรไฟล์หาเมท (UC-01)
- การติดต่อหรือแชทกับรูมเมท

## Constraints
- CON-CCM-01 นักศึกษาต้องเข้าสู่ระบบก่อนจึงสามารถยกเลิกการจับคู่ได้
- CON-CCM-02 นักศึกษาต้องมีสถานะจับคู่สำเร็จก่อนจึงสามารถยกเลิกการจับคู่ได้
- CON-CCM-03 ระบบต้องแสดงข้อมูลคู่ที่นักศึกษาต้องการยกเลิกก่อนดำเนินการ
- CON-CCM-04 ระบบต้องให้นักศึกษายืนยันก่อนยกเลิกการจับคู่
- CON-CCM-05 หากนักศึกษาไม่ยืนยันการยกเลิก ระบบต้องไม่เปลี่ยนแปลงสถานะการจับคู่
- CON-CCM-06 ระบบต้องตรวจสอบสมาชิกของคู่และสถานะ "จับคู่สำเร็จ" แบบ atomic ก่อนบันทึกการยกเลิก
- CON-CCM-07 การยกเลิกการจับคู่ต้องทำให้แชทเดิมอ่านประวัติได้อย่างเดียวและไม่สามารถส่งข้อความใหม่ได้

## Requirements
- FR-CCM-01 ระบบต้องให้นักศึกษาสามารถเปิดหน้าสถานะการจับคู่ได้
- FR-CCM-02 ระบบต้องให้นักศึกษาสามารถเลือกคู่ที่ต้องการยกเลิกได้
- FR-CCM-03 ระบบต้องให้นักศึกษาสามารถเลือก "ยกเลิกการจับคู่" ได้
- FR-CCM-04 ระบบต้องแสดงข้อความเพื่อยืนยันการยกเลิกการจับคู่
- FR-CCM-05 ระบบต้องให้นักศึกษาสามารถยืนยันหรือยกเลิกการดำเนินการได้
- FR-CCM-06 เมื่อยืนยันการยกเลิก ระบบต้องเปลี่ยนสถานะการจับคู่เป็น "ยกเลิก"
- FR-CCM-07 ระบบต้องแจ้งผลการยกเลิกการจับคู่ให้นักศึกษาทราบ
- FR-CCM-08 เมื่อยกเลิกการจับคู่สำเร็จ นักศึกษาต้องสามารถกลับไปค้นหาและจับคู่กับเมทใหม่ได้
- FR-CCM-09 เมื่อยกเลิกการจับคู่ ระบบต้องแสดงสถานะ "ยกเลิก" ให้ทั้งสองฝ่าย
- FR-CCM-10 เมื่อยกเลิกการจับคู่ ระบบต้องแจ้งอีกฝ่ายในระบบและผ่าน push notification
- FR-CCM-11 หลังยกเลิกการจับคู่ โปรไฟล์ของทั้งสองฝ่ายต้องกลับมาแสดงในผลการค้นหา หากเปิดสถานะให้ค้นหา
- FR-CCM-12 นักศึกษาต้องสามารถส่งคำขอและจับคู่กับคู่เดิมได้อีกครั้ง หากทั้งสองฝ่ายเปิดสถานะให้ค้นหา
- FR-CCM-13 ระบบต้องตรวจสอบและเปลี่ยนสถานะการจับคู่เป็น "ยกเลิก" แบบ atomic
- FR-CCM-14 ระบบต้องเปลี่ยนแชทเดิมเป็นโหมดอ่านอย่างเดียวหลังยกเลิกการจับคู่
- FR-CCM-15 ระบบต้องลองส่งการแจ้งเตือนการยกเลิกซ้ำอัตโนมัติไม่เกิน 3 ครั้งเมื่อการแจ้งเตือนครั้งแรกล้มเหลว

## Quality Requirements
- NFR-CCM-01 ระบบต้องอนุญาตให้เฉพาะนักศึกษาที่เป็นสมาชิกของคู่ที่จับคู่สำเร็จสามารถยกเลิกการจับคู่ดังกล่าวได้
- NFR-CCM-02 ระบบต้องไม่เปลี่ยนสถานะการจับคู่ หากนักศึกษาไม่ยืนยันการยกเลิก
- NFR-CCM-03 ระบบต้องแสดงข้อความยืนยันอย่างชัดเจนก่อนยกเลิกการจับคู่
- NFR-CCM-04 ในการทดสอบกับนักศึกษาที่ไม่เคยยกเลิกการจับคู่ 5 คน อย่างน้อย 80% ต้องยกเลิกสำเร็จโดยไม่รับคำแนะนำ
- NFR-CCM-05 หากบันทึกการยกเลิกล้มเหลว ระบบต้องคงสถานะจับคู่สำเร็จและให้ลองใหม่
- NFR-CCM-06 หากแจ้งเตือนการยกเลิกล้มเหลว ระบบต้องคงสถานะยกเลิกและแจ้งว่าไม่สามารถส่งการแจ้งเตือนได้
- NFR-CCM-07 ระบบต้องไม่บันทึกการยกเลิกหากผู้ดำเนินการไม่ใช่สมาชิกหรือสถานะการจับคู่ไม่ใช่ "จับคู่สำเร็จ"

## Acceptance Criteria
- [ ] AC-CCM-01 (FR-CCM-01, FR-CCM-02)
      Given นักศึกษาเข้าสู่ระบบแล้วและมีสถานะจับคู่สำเร็จ
      When นักศึกษาเปิดหน้าสถานะการจับคู่และเลือกคู่ที่ต้องการยกเลิก
      Then ระบบแสดงข้อมูลของคู่ที่นักศึกษาเลือก

- [ ] AC-CCM-02 (FR-CCM-03, FR-CCM-04)
      Given นักศึกษาเลือกคู่ที่ต้องการยกเลิก
      When นักศึกษาเลือก "ยกเลิกการจับคู่"
      Then ระบบแสดงข้อความเพื่อยืนยันการยกเลิกการจับคู่

- [ ] AC-CCM-03 (FR-CCM-05, FR-CCM-06, FR-CCM-07)
      Given ระบบแสดงข้อความยืนยันการยกเลิก
      When นักศึกษายืนยันการยกเลิก
      Then ระบบเปลี่ยนสถานะการจับคู่เป็น "ยกเลิก" และแจ้งผลการยกเลิกการจับคู่ให้นักศึกษาทราบ

- [ ] AC-CCM-03D (CON-CCM-06, FR-CCM-13)
      Given นักศึกษาเป็นสมาชิกของคู่ที่มีสถานะ "จับคู่สำเร็จ"
      When นักศึกษายืนยันการยกเลิก
      Then ระบบตรวจสอบสมาชิกและสถานะแบบ atomic แล้วเปลี่ยนสถานะการจับคู่เป็น "ยกเลิก"

- [ ] AC-CCM-03A (FR-CCM-09, FR-CCM-10)
      Given นักศึกษายืนยันการยกเลิกการจับคู่
      When ระบบบันทึกการยกเลิกสำเร็จ
      Then ระบบแสดงสถานะ "ยกเลิก" ให้ทั้งสองฝ่าย และแจ้งอีกฝ่ายในระบบและผ่าน push notification

- [ ] AC-CCM-03B (NFR-CCM-05)
      Given นักศึกษายืนยันการยกเลิกการจับคู่
      When การบันทึกการยกเลิกล้มเหลว
      Then ระบบคงสถานะ "จับคู่สำเร็จ" แจ้งข้อผิดพลาด และให้นักศึกษาลองใหม่

- [ ] AC-CCM-03C (NFR-CCM-06)
      Given ระบบบันทึกการยกเลิกสำเร็จ
      When การแจ้งเตือนอีกฝ่ายล้มเหลว
      Then ระบบลองส่งการแจ้งเตือนซ้ำไม่เกิน 3 ครั้ง คงสถานะ "ยกเลิก" และแจ้งว่าไม่สามารถส่งการแจ้งเตือนได้หากยังไม่สำเร็จ

- [ ] AC-CCM-03E (CON-CCM-07, FR-CCM-14)
      Given นักศึกษายกเลิกการจับคู่สำเร็จและมีประวัติแชทกับคู่ดังกล่าว
      When นักศึกษาเปิดแชทเดิม
      Then ระบบให้ดูประวัติได้ แต่ไม่อนุญาตให้ส่งข้อความใหม่

- [ ] AC-CCM-04 (FR-CCM-05)
      Given ระบบแสดงข้อความยืนยันการยกเลิก
      When นักศึกษาไม่ยืนยันการยกเลิก
      Then ระบบยกเลิกการดำเนินการและไม่เปลี่ยนแปลงสถานะการจับคู่

- [ ] AC-CCM-05 (FR-CCM-08)
      Given นักศึกษายกเลิกการจับคู่สำเร็จ
      When นักศึกษากลับไปยังระบบค้นหาเมท
      Then นักศึกษาสามารถค้นหาและส่งคำขอเป็นเมทใหม่ได้

- [ ] AC-CCM-05A (FR-CCM-11)
      Given ทั้งสองฝ่ายยกเลิกการจับคู่แล้วและเปิดสถานะให้ค้นหา
      When นักศึกษาค้นหาเมท
      Then โปรไฟล์ของทั้งสองฝ่ายกลับมาแสดงในผลการค้นหาได้

- [ ] AC-CCM-05B (FR-CCM-12)
      Given ทั้งสองฝ่ายยกเลิกการจับคู่และเปิดสถานะให้ค้นหา
      When นักศึกษาส่งคำขอเป็นเมทไปยังคู่เดิม
      Then ระบบอนุญาตให้ส่งคำขอและเริ่มกระบวนการจับคู่ใหม่

- [ ] AC-CCM-06 (NFR-CCM-01)
      Given นักศึกษาเข้าสู่ระบบแล้วแต่ไม่ได้เป็นสมาชิกของคู่ที่เลือก
      When นักศึกษาพยายามยกเลิกการจับคู่
      Then ระบบปฏิเสธการดำเนินการดังกล่าว

- [ ] AC-CCM-07 (NFR-CCM-04)
      Given นักศึกษาที่ไม่เคยใช้ฟังก์ชันยกเลิกการจับคู่จำนวน 5 คน
      When นักศึกษาแต่ละคนยกเลิกการจับคู่
      Then อย่างน้อย 4 คนยกเลิกสำเร็จโดยไม่รับคำแนะนำ

## Assumptions & Open Questions
- ASM-CCM-01 นักศึกษาต้องเข้าสู่ระบบก่อนใช้งานฟังก์ชันยกเลิกการจับคู่
- ASM-CCM-02 นักศึกษาต้องมีสถานะจับคู่สำเร็จก่อนยกเลิกการจับคู่
- ASM-CCM-03 ระบบสามารถตรวจสอบสมาชิกของคู่ที่จับคู่สำเร็จได้
- ASM-CCM-04 เมื่อยกเลิกการจับคู่แล้ว นักศึกษาสามารถกลับไปหาเมทใหม่ได้

- Q-CCM-01 เมื่อฝ่ายหนึ่งยกเลิกการจับคู่ สถานะของอีกฝ่ายจะแสดงเป็นอะไร?
-> ตอบแล้ว: ทั้งสองฝ่ายเห็นสถานะ "ยกเลิก" เหมือนกัน
- Q-CCM-02 หลังยกเลิกการจับคู่แล้ว - โปรไฟล์ของทั้งสองฝ่ายจะกลับมาแสดงในผลการค้นหาทันทีหรือไม่?
-> ตอบแล้ว: กลับมาแสดงทันทีหากทั้งสองฝ่ายเปิดสถานะให้ค้นหา
- Q-CCM-03 ระบบต้องแจ้งให้อีกฝ่ายทราบเมื่อมีการยกเลิกการจับคู่หรือไม่?
-> ตอบแล้ว: ต้องแจ้งเตือนในระบบและผ่าน push notification
- Q-CCM-04 นักศึกษาสามารถกลับมาจับคู่กับคนเดิมได้หรือไม่?
-> ตอบแล้ว: ได้ทันที หากทั้งสองฝ่ายยังเปิดสถานะให้ค้นหา
- Q-CCM-05 หลังยกเลิกการจับคู่ แชทเดิมควรใช้งานอย่างไร?
-> ตอบแล้ว: อ่านประวัติได้อย่างเดียวและห้ามส่งข้อความใหม่
- Q-CCM-06 การยกเลิกการจับคู่ต้องตรวจสอบสถานะและสมาชิกแบบ atomic หรือไม่?
-> ตอบแล้ว: ต้องตรวจสอบและเปลี่ยนสถานะแบบ atomic
- Q-CCM-07 หากแจ้งเตือนการยกเลิกล้มเหลว ต้องลองซ้ำกี่ครั้ง?
-> ตอบแล้ว: ลองส่งซ้ำอัตโนมัติ 3 ครั้ง แล้วคงสถานะ "ยกเลิก"
