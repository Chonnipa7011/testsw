# Plan v1: Align match status specification

## Problem and approach

ปรับ [spec.md](spec.md) จาก Draft v2 เป็น Draft v3 ให้ชัดเจนเรื่องรายการที่ยกเลิก การยกเลิกคำขอจากหน้านี้ ขอบเขตกับ UC-09 และพฤติกรรมการรีเฟรชข้อมูล

## Scope decisions

- รายการที่มีสถานะ `ยกเลิก` ไม่แสดงในหน้าสถานะการจับคู่
- หน้านี้ให้ผู้ส่งยกเลิกได้เฉพาะคำขอที่ `รอการตอบรับ`; การยกเลิก `จับคู่สำเร็จ` อยู่ใน UC-09
- ระบบดึงข้อมูลใหม่เมื่อเปิดหน้าและเมื่อผู้ใช้กดปุ่มรีเฟรช โดยไม่กำหนด real-time refresh

## Tasks

1. ปรับขอบเขตสถานะที่แสดง รวมถึงการซ่อนรายการที่ยกเลิก
2. ระบุสิทธิ์ยกเลิกคำขอรอและแยกการยกเลิกการจับคู่สำเร็จไปยัง UC-09
3. ระบุพฤติกรรมการรีเฟรชเมื่อเปิดหน้าและกดปุ่มรีเฟรช
4. ปรับ requirements, acceptance criteria, assumptions และ traceability ให้สอดคล้องกับ v3
5. ตรวจ diff และ markdown consistency แล้ว commit เป็น `Draft v3`

## Notes and considerations

- ต้องไม่ทำให้รายการที่จับคู่สำเร็จถูกซ่อนเพียงเพราะยังมีรายการยกเลิก
- ต้องไม่ให้ UC-08 แทนที่ flow ยกเลิกการจับคู่ของ UC-09
- เมื่อรีเฟรชล้มเหลวต้องคงข้อมูลเดิมและแสดงข้อผิดพลาด
- ต้องไม่แก้ไฟล์ attachment แบบ read-only และต้องคงการเปลี่ยนแปลงที่ไม่เกี่ยวข้องใน working tree
