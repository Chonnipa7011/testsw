# Plan v1: Align chat roommate specification

## Problem and approach

ปรับ [spec.md](spec.md) จาก Draft v2 เป็น Draft v3 ให้ชัดเจนเรื่องสิทธิ์การเริ่มแชท สถานะของแชทเดิม การส่งซ้ำเมื่อผิดพลาด และอายุไฟล์แนบ พร้อมปรับ acceptance criteria และ traceability ให้ทดสอบได้

## Scope decisions

- ผู้ใช้เริ่มแชทกับนักศึกษาที่มีโปรไฟล์เปิดให้ค้นหาได้ทันที
- เมื่อฝ่ายใดปิดสถานะหาเมทหรือโปรไฟล์ไม่พร้อมให้ค้นหา แชทเดิมอ่านได้อย่างเดียวและส่งข้อความใหม่ไม่ได้
- ระบบลองส่งข้อความซ้ำอัตโนมัติสูงสุด 3 ครั้ง ก่อนแสดงสถานะล้มเหลวให้ผู้ใช้ลองใหม่เอง
- ไฟล์แนบเก็บและดาวน์โหลดได้ 30 วันนับจากเวลาที่ส่งสำเร็จ

## Tasks

1. ปรับสิทธิ์การเริ่มแชทและเงื่อนไขการเข้าถึงบทสนทนา
2. ระบุพฤติกรรมแชทเดิมเมื่อโปรไฟล์ไม่พร้อมให้ค้นหา
3. ระบุ retry, failure handling และอายุการเก็บไฟล์แนบ
4. ปรับ requirements, acceptance criteria, assumptions และ traceability ให้สอดคล้องกับ v3
5. ตรวจ diff และ markdown consistency แล้ว commit เป็น `Draft v3`

## Notes and considerations

- ต้องคงสิทธิ์ไม่ให้ผู้ใช้นอกบทสนทนาเข้าถึงข้อความหรือไฟล์แนบ
- ต้องแยกสิทธิ์การเริ่มแชทใหม่ออกจากการอ่านประวัติแชทเดิม
- ต้องไม่ให้การเก็บไฟล์แนบเกิน 30 วันขัดกับการแสดงประวัติข้อความ
- ต้องไม่แก้ไฟล์ attachment แบบ read-only และต้องคงการเปลี่ยนแปลงที่ไม่เกี่ยวข้องใน working tree
