# Feature: ปิดสถานะหาเมท (Close Roommate Status)
Spec ID: SPEC-CRS-010 | Source: SRS ข้อ ... (FR-CRS) | Use case: UC-10
Owner: ทีม vista and friend | Status: Draft v3 | Updated: 2569-09-20

## Goal
นักศึกษาสามารถปิดสถานะหาเมทของตนเอง
เพื่อหยุดการแสดงโปรไฟล์ในระบบค้นหาเมทและไม่รับคำขอเป็นเมทใหม่

## Scope
### In scope
- เปิดหน้าโปรไฟล์
- เลือกปิดสถานะหาเมท
- แสดงข้อความยืนยัน
- ยืนยันการปิดสถานะ
- เปลี่ยนสถานะเป็น "ไม่กำลังหาเมท"
- ไม่แสดงโปรไฟล์ในผลการค้นหา
- ไม่รับคำขอเป็นเมทใหม่
- ปฏิเสธคำขอเป็นเมทที่รอการตอบรับและแจ้งผู้ส่ง
- เปลี่ยนแชทเดิมเป็นโหมดอ่านอย่างเดียว
- เปิดสถานะกลับเป็น "กำลังหาเมท"

### Out of scope
- การสร้างโปรไฟล์หาเมท (UC-01)
- การแก้ไขโปรไฟล์หาเมท (UC-02)
- การระบุความต้องการหาเมท (UC-03)
- การค้นหาเมท (UC-04)
- การส่งคำขอเป็นเมท (UC-06)
- การรับหรือปฏิเสธคำขอเป็นเมท (UC-07)
- การแสดงสถานะการจับคู่ (UC-08)
- การยกเลิกการจับคู่ (UC-09)

## Constraints
- CON-CRS-01 นักศึกษาต้องเข้าสู่ระบบก่อนจึงสามารถปิดสถานะหาเมทได้
- CON-CRS-02 นักศึกษาต้องมีโปรไฟล์หาเมทก่อนจึงสามารถปิดสถานะได้
- CON-CRS-03 ระบบต้องให้นักศึกษายืนยันก่อนเปลี่ยนสถานะหาเมท
- CON-CRS-04 เมื่อปิดสถานะหาเมท ระบบต้องเปลี่ยนสถานะเป็น "ไม่กำลังหาเมท"
- CON-CRS-05 โปรไฟล์ของนักศึกษาที่ปิดสถานะหาเมทแล้วต้องไม่ปรากฏในผลการค้นหา
- CON-CRS-06 นักศึกษาที่อยู่ในสถานะ "ไม่กำลังหาเมท" ต้องไม่สามารถรับคำขอเป็นเมทใหม่ได้
- CON-CRS-07 หากนักศึกษาไม่ยืนยันการปิดสถานะ ระบบต้องไม่เปลี่ยนแปลงสถานะหาเมท
- CON-CRS-08 เมื่อปิดสถานะ คำขอที่รอการตอบรับทั้งหมดต้องถูกปฏิเสธโดยอัตโนมัติ
- CON-CRS-09 การปิดสถานะไม่กระทบสถานะจับคู่สำเร็จ
- CON-CRS-10 การเปิดสถานะกลับต้องได้รับการยืนยันก่อนเปลี่ยนเป็น "กำลังหาเมท"
- CON-CRS-11 การเปลี่ยนสถานะเป็น "ไม่กำลังหาเมท" และการปฏิเสธคำขอที่รอทั้งหมดต้องสำเร็จหรือล้มเหลวพร้อมกันใน atomic operation เดียว
- CON-CRS-12 เมื่อปิดสถานะแล้ว แชทเดิมของผู้เข้าร่วมต้องอ่านประวัติได้อย่างเดียวและห้ามส่งข้อความใหม่

## Requirements
- FR-CRS-01 ระบบต้องให้นักศึกษาสามารถเปิดหน้าโปรไฟล์ได้
- FR-CRS-02 ระบบต้องให้นักศึกษาสามารถเลือก "ปิดสถานะหาเมท" ได้
- FR-CRS-03 ระบบต้องแสดงข้อความเพื่อยืนยันการปิดสถานะหาเมท
- FR-CRS-04 ระบบต้องให้นักศึกษาสามารถยืนยันการปิดสถานะได้
- FR-CRS-05 เมื่อยืนยันการปิดสถานะ ระบบต้องเปลี่ยนสถานะเป็น "ไม่กำลังหาเมท"
- FR-CRS-06 ระบบต้องไม่แสดงโปรไฟล์ของนักศึกษาที่มีสถานะ "ไม่กำลังหาเมท" ในผลการค้นหา
- FR-CRS-07 ระบบต้องไม่อนุญาตให้ผู้ใช้งานส่งคำขอเป็นเมทใหม่ไปยังนักศึกษาที่มีสถานะ "ไม่กำลังหาเมท"
- FR-CRS-08 หากนักศึกษาไม่ยืนยันการปิดสถานะ ระบบต้องไม่เปลี่ยนแปลงสถานะหาเมท
- FR-CRS-09 ระบบต้องให้นักศึกษาเปิดสถานะกลับเป็น "กำลังหาเมท" ได้
- FR-CRS-10 เมื่อปิดสถานะ ระบบต้องปฏิเสธคำขอที่รอการตอบรับทั้งหมดโดยอัตโนมัติ
- FR-CRS-11 ระบบต้องแจ้งผู้ส่งคำขอที่ถูกปฏิเสธอัตโนมัติในระบบและผ่าน push notification
- FR-CRS-12 เมื่อเปิดสถานะกลับสำเร็จ โปรไฟล์ต้องแสดงในผลการค้นหาและรับคำขอใหม่ได้ทันที
- FR-CRS-13 ระบบต้องลองส่งการแจ้งเตือนการปฏิเสธคำขอซ้ำอัตโนมัติไม่เกิน 3 ครั้งเมื่อการแจ้งเตือนครั้งแรกล้มเหลว
- FR-CRS-14 ระบบต้องเปลี่ยนแชทเดิมเป็นโหมดอ่านอย่างเดียวเมื่อปิดสถานะหาเมท

## Quality Requirements
- NFR-CRS-01 ระบบต้องอนุญาตให้เฉพาะเจ้าของโปรไฟล์ที่เข้าสู่ระบบแล้วสามารถเปลี่ยนสถานะหาเมทของตนเองได้
- NFR-CRS-02 ระบบต้องปรับปรุงสถานะและผลการค้นหาให้สอดคล้องกับสถานะล่าสุดของนักศึกษา
- NFR-CRS-03 ระบบต้องแสดงข้อความยืนยันอย่างชัดเจนก่อนปิดสถานะหาเมท
- NFR-CRS-04 ระบบต้องแสดงข้อความยืนยันอย่างชัดเจนก่อนเปิดสถานะกลับ
- NFR-CRS-05 หากบันทึกการปิดหรือเปิดสถานะล้มเหลว ระบบต้องคงสถานะเดิม แจ้งข้อผิดพลาด และให้ลองใหม่
- NFR-CRS-06 ในการทดสอบกับนักศึกษาที่ไม่เคยใช้การเปิด/ปิดสถานะ 5 คน อย่างน้อย 80% ต้องเปลี่ยนสถานะสำเร็จโดยไม่รับคำแนะนำ
- NFR-CRS-07 หากการแจ้งเตือนการปฏิเสธคำขอล้มเหลวหลังลองซ้ำครบ 3 ครั้ง ระบบต้องคงสถานะคำขอเป็น "ปฏิเสธ" และแสดงสถานะการแจ้งเตือนล้มเหลวเพื่อให้ติดตามได้

## Acceptance Criteria
- [ ] AC-CRS-01 (FR-CRS-01, FR-CRS-02)
      Given นักศึกษาเข้าสู่ระบบแล้วและมีโปรไฟล์หาเมท
      When นักศึกษาเปิดหน้าโปรไฟล์และเลือก "ปิดสถานะหาเมท"
      Then ระบบแสดงข้อความเพื่อยืนยันการปิดสถานะ

- [ ] AC-CRS-02 (FR-CRS-03, FR-CRS-04, FR-CRS-05)
      Given ระบบแสดงข้อความยืนยันการปิดสถานะ
      When นักศึกษายืนยันการปิดสถานะ
      Then ระบบเปลี่ยนสถานะเป็น "ไม่กำลังหาเมท"

- [ ] AC-CRS-02A (CON-CRS-08, FR-CRS-10)
      Given นักศึกษามีคำขอเป็นเมทที่ยังรอการตอบรับ
      When นักศึกษายืนยันการปิดสถานะหาเมท
      Then ระบบเปลี่ยนสถานะเป็น "ไม่กำลังหาเมท" และปฏิเสธคำขอที่รอทั้งหมดโดยอัตโนมัติใน atomic operation เดียว

- [ ] AC-CRS-02B (CON-CRS-09)
      Given นักศึกษามีสถานะจับคู่สำเร็จ
      When นักศึกษายืนยันการปิดสถานะหาเมท
      Then ระบบปิดสถานะหาเมทโดยไม่เปลี่ยนสถานะจับคู่สำเร็จ

- [ ] AC-CRS-02C (CON-CRS-11, NFR-CRS-05)
      Given นักศึกษายืนยันการปิดสถานะหาเมท
      When การเปลี่ยนสถานะหรือการปฏิเสธคำขอที่รอรายการใดรายการหนึ่งล้มเหลว
      Then ระบบไม่บันทึกการเปลี่ยนแปลงบางส่วน คงสถานะเดิมและคำขอเดิมไว้ พร้อมแจ้งข้อผิดพลาดให้ลองใหม่

- [ ] AC-CRS-03 (FR-CRS-06)
      Given นักศึกษามีสถานะ "ไม่กำลังหาเมท"
      When ระบบแสดงผลการค้นหาเมท
      Then ระบบไม่แสดงโปรไฟล์ของนักศึกษาดังกล่าวในผลการค้นหา

- [ ] AC-CRS-04 (FR-CRS-07)
      Given นักศึกษามีสถานะ "ไม่กำลังหาเมท"
      When นักศึกษาคนอื่นพยายามส่งคำขอเป็นเมท
      Then ระบบไม่อนุญาตให้ส่งคำขอใหม่

- [ ] AC-CRS-05 (FR-CRS-08)
      Given ระบบแสดงข้อความยืนยันการปิดสถานะ
      When นักศึกษาไม่ยืนยันการปิดสถานะ
      Then ระบบยกเลิกการดำเนินการและไม่เปลี่ยนแปลงสถานะหาเมท

- [ ] AC-CRS-06 (NFR-CRS-01)
      Given นักศึกษาเข้าสู่ระบบแล้ว
      When นักศึกษาพยายามเปลี่ยนสถานะหาเมทของโปรไฟล์ของนักศึกษาคนอื่น
      Then ระบบปฏิเสธการดำเนินการดังกล่าว

- [ ] AC-CRS-07 (FR-CRS-09, NFR-CRS-04)
      Given นักศึกษามีสถานะ "ไม่กำลังหาเมท"
      When นักศึกษาเลือกเปิดสถานะกลับ
      Then ระบบแสดงข้อความยืนยัน และเมื่อยืนยันให้เปลี่ยนสถานะเป็น "กำลังหาเมท"

- [ ] AC-CRS-08 (FR-CRS-11)
      Given ระบบปฏิเสธคำขอที่รอการตอบรับโดยอัตโนมัติ
      When ระบบแจ้งผลแก่ผู้ส่งคำขอ
      Then ระบบแจ้งเตือนในระบบและส่ง push notification โดยลองส่งซ้ำอัตโนมัติไม่เกิน 3 ครั้งเมื่อครั้งแรกล้มเหลว

- [ ] AC-CRS-08A (FR-CRS-13, NFR-CRS-07)
      Given ระบบปฏิเสธคำขอที่รอการตอบรับแล้ว
      When การแจ้งเตือนผู้ส่งล้มเหลวหลังลองซ้ำครบ 3 ครั้ง
      Then ระบบคงสถานะคำขอเป็น "ปฏิเสธ" และบันทึกหรือแสดงสถานะว่าการแจ้งเตือนไม่สำเร็จ

- [ ] AC-CRS-08B (CON-CRS-12, FR-CRS-14)
      Given นักศึกษามีแชทเดิมกับคู่สนทนา
      When นักศึกษาปิดสถานะหาเมทสำเร็จ
      Then ระบบยังให้เปิดดูประวัติแชทได้ แต่ไม่อนุญาตให้ส่งข้อความใหม่

- [ ] AC-CRS-09 (FR-CRS-12)
      Given นักศึกษายืนยันเปิดสถานะกลับและบันทึกสำเร็จ
      When นักศึกษาหรือผู้ใช้อื่นค้นหาเมท
      Then โปรไฟล์กลับมาแสดงในผลการค้นหาและรับคำขอใหม่ได้ทันที

- [ ] AC-CRS-10 (NFR-CRS-05)
      Given นักศึกษากำลังปิดหรือเปิดสถานะหาเมท
      When การบันทึกสถานะล้มเหลว
      Then ระบบคงสถานะเดิม แจ้งข้อผิดพลาด และให้ลองใหม่

- [ ] AC-CRS-11 (NFR-CRS-06)
      Given นักศึกษาที่ไม่เคยใช้ฟังก์ชันนี้จำนวน 5 คน
      When นักศึกษาแต่ละคนเปิดหรือปิดสถานะหาเมท
      Then อย่างน้อย 4 คนดำเนินการสำเร็จโดยไม่รับคำแนะนำ

## Assumptions & Open Questions
- ASM-CRS-01 นักศึกษาต้องเข้าสู่ระบบก่อนใช้งานฟังก์ชันปิดสถานะหาเมท
- ASM-CRS-02 นักศึกษาต้องมีโปรไฟล์หาเมทก่อนปิดสถานะ
- ASM-CRS-03 ระบบมีสถานะ "กำลังหาเมท" และ "ไม่กำลังหาเมท"
- ASM-CRS-04 ระบบสามารถตรวจสอบสถานะของโปรไฟล์ก่อนแสดงผลการค้นหาและรับคำขอใหม่ได้

- Q-CRS-01 หลังปิดสถานะหาเมทแล้ว นักศึกษาสามารถเปิดสถานะกลับมาได้หรือไม่?
-> ตอบแล้ว: เปิดสถานะกลับได้และต้องยืนยันก่อน
- Q-CRS-02 หากมีคำขอเป็นเมทที่รอการตอบรับอยู่แล้ว จะเกิดอะไรขึ้นเมื่อปิดสถานะ?
-> ตอบแล้ว: ปฏิเสธคำขอที่รอทั้งหมดโดยอัตโนมัติและแจ้งผู้ส่ง
- Q-CRS-03 หากมีสถานะจับคู่สำเร็จอยู่แล้ว นักศึกษาสามารถปิดสถานะหาเมทได้หรือไม่?
-> ตอบแล้ว: ปิดได้โดยไม่กระทบสถานะจับคู่สำเร็จ
- Q-CRS-04 การปิดสถานะหาเมทต้องแจ้งเตือนผู้ที่เคยส่งคำขอไว้หรือไม่?
-> ตอบแล้ว: แจ้งเตือนในระบบและผ่าน push notification
- Q-CRS-05 การปิดสถานะและการปฏิเสธคำขอที่รอต้องทำงานอย่างไรเมื่อมีความล้มเหลว?
-> ตอบแล้ว: ทำเป็น atomic operation เดียว หากส่วนใดล้มเหลวให้คงสถานะและคำขอเดิมทั้งหมด
- Q-CRS-06 หากการแจ้งเตือนผู้ส่งคำขอล้มเหลว ต้องลองซ้ำกี่ครั้งและคงสถานะใด?
-> ตอบแล้ว: ลองซ้ำอัตโนมัติ 3 ครั้ง แล้วคงสถานะคำขอเป็น "ปฏิเสธ" พร้อมบันทึกความล้มเหลว
- Q-CRS-07 การปิดสถานะมีผลต่อแชทเดิมอย่างไร?
-> ตอบแล้ว: แชทยังเปิดดูประวัติได้ แต่เป็นโหมดอ่านอย่างเดียวและส่งข้อความใหม่ไม่ได้
